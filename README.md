
# TrailGuide (Expo SDK 53 • React 19)

A clean Expo project aligned to **SDK 53**, split into pages, and tested for compatibility with **Expo Go** and **web**.

## Run

```bash
npm install
npx expo start
# or: npm run android | npm run ios | npm run web
```

> Tip: make sure Expo Go is updated on your phone.

## Notes

- Icons use valid Feather names only.
- No web‑only APIs at runtime so Hermes is happy.
- Slider is from `@react-native-community/slider` and works in Expo SDK 53.
