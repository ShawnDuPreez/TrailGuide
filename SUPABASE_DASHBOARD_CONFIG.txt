STEP 1: REDIRECT URLs
Location: Authentication → URL Configuration → Redirect URLs

Add these URLs (click "Add URL" for each):

    trailguide://auth-callback
    http://localhost:3000/callback

═══════════════════════════════════════════════════════════════

STEP 2: SITE URL
Location: Authentication → URL Configuration → Site URL

Set to:

    trailguide://auth-callback

═══════════════════════════════════════════════════════════════

STEP 3: EMAIL PROVIDER
Location: Authentication → Providers → Email

Settings:
    ☑ Enable Email provider
    ☑ Confirm email (if you want verification)
    
    Confirm email redirect URL:
    trailguide://auth-callback

═══════════════════════════════════════════════════════════════

STEP 4: GOOGLE PROVIDER (if using Google OAuth)
Location: Authentication → Providers → Google

Settings:
    ☑ Enable Google provider
    Add your Google OAuth credentials:
        - Client ID: (from Google Cloud Console)
        - Client Secret: (from Google Cloud Console)

═══════════════════════════════════════════════════════════════

STEP 5: REBUILD APP

Run in terminal:

    ./gradlew clean
    ./gradlew installDebug

═══════════════════════════════════════════════════════════════

VERIFICATION:

Test deep link:
    adb shell am start -W -a android.intent.action.VIEW -d "trailguide://auth-callback" com.trailguide.android

Watch logs:
    adb logcat | grep -i "MainActivity"

═══════════════════════════════════════════════════════════════

THAT'S IT! ✅

After completing these steps:
✅ Google sign-in will work without canceling
✅ Email verification links will open the app
✅ OAuth callbacks will be handled correctly
